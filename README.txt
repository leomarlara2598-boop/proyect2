# CDI Los Mangos — versión adaptada al diagrama

Esta versión conserva la idea visual del código entregado y reorganiza la navegación para cubrir los casos de uso del diagrama:

ACTORES
- Usuario de consultas
- Bibliotecario
- Administrador

CASOS CUBIERTOS
- Iniciar sesión / recuperación
- Consultar inventario de libros
- Listar libros
- Registrar libros
- Modificar libros
- Habilitar / inhabilitar inventario/libros
- Procesar préstamo
- Procesar devolución
- Listar préstamos
- Listar lector
- Registrar lector
- Modificar lector
- Habilitar / inhabilitar lector
- Listar donación
- Registrar donación
- Editar donación
- Consultar inventario de bienes e insumos
- Listar plan de actividades
- Registrar actividad
- Modificar actividad
- Listar reportes
- Listar usuario
- Añadir usuario
- Habilitar / inhabilitar usuario
- Editar usuario

Todos los formularios son prototipos HTML/CSS. Los botones de guardar/confirmar navegan a la lista correspondiente, pero no persisten datos porque todavía no hay backend/base de datos.
